# Data Analysis Workflow

1. Clarify the decision or question the analysis should support.
2. Inspect data source, schema, units, time coverage, and provenance.
3. Preserve raw data; create reproducible transformed datasets.
4. Assess data quality: types, missing values, duplicates, outliers, and inconsistent categories.
5. Choose methods appropriate to the question and state assumptions.
6. Validate calculations and check sensitivity to key choices.
7. Use clear labels, units, and appropriate visualizations.
8. Avoid causal claims from observational patterns without a valid design.
9. Document code, transformations, limitations, and reproducibility steps.
10. Protect confidential and personal data.
